# Updated Scratch Curriculum (Days 1–2)

These folders are the **Scratch** portion of the DSTI Coding and Robotics **train-the-trainer** curriculum for the period 2026–2028.

| Folder | Content |
|--------|--------|
| **day-01-scratch** | Introduction to Scratch, lesson plan, activities, assessment, project templates, **Interactive Story memo + facilitator annotations**, and working **`.sb3`** solution |
